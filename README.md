# Islamic Credit Scoring System

ระบบประเมินความเสี่ยงสินเชื่อสำหรับสหกรณ์อิสลาม แบ่งการทำงานเป็น 2 ชั้น คือ การคัดกรองคุณสมบัติเบื้องต้นตามระเบียบสหกรณ์ (Rule-based Pre-screening) และการประเมินความน่าจะเป็นในการเกิดหนี้เสียด้วย Machine Learning (Random Forest) พร้อมคำนวณจุดตัดความเสี่ยงตามต้นทุนทางธุรกิจ (Business Cost Matrix)

## การติดตั้งและเริ่มต้นใช้งาน

1. สร้างและเปิดใช้งาน Virtual Environment
```bash
python -m venv venv

# สำหรับ Windows
venv\Scripts\activate

# สำหรับ macOS / Linux
source venv/bin/activate
```

2. ติดตั้งไลบรารีที่จำเป็น
```bash
pip install -r requirements.txt
```

3. รัน Pipeline เพื่อสร้างข้อมูล เทรนโมเดล และคำนวณจุดตัดความเสี่ยง
```bash
python main.py
```
เมื่อรันเสร็จ ระบบจะบันทึกไฟล์โมเดลไว้ที่ `models/best_credit_model.pkl`

4. เปิดใช้งานหน้า Web Application
```bash
streamlit run app/app.py
```

## ตรรกะการทำงานของระบบ

### 1. เกณฑ์คัดกรองเบื้องต้น (`src/pre_screening.py`)
ผู้ขอสินเชื่อจะถูกตรวจสอบเงื่อนไข 4 ข้อก่อนส่งข้อมูลเข้าโมเดล AI:
1. อายุสมาชิก: ข้าราชการ/รัฐวิสาหกิจ ต้องเป็นสมาชิกอย่างน้อย 3 เดือน อาชีพอื่นต้องเป็นสมาชิกอย่างน้อย 12 เดือน
2. ทุนเรือนหุ้นขั้นต่ำแบบขั้นบันได:
   - วงเงินไม่เกิน 300,000 บาท: ทุนเรือนหุ้น >= 15%
   - วงเงินไม่เกิน 500,000 บาท: ทุนเรือนหุ้น >= 13%
   - วงเงินไม่เกิน 700,000 บาท: ทุนเรือนหุ้น >= 11%
   - วงเงินไม่เกิน 1,000,000 บาท: ทุนเรือนหุ้น >= 9%
   - วงเงินไม่เกิน 3,000,000 บาท: ทุนเรือนหุ้น >= 7%
   - วงเงินมากกว่า 3,000,000 บาท: ทุนเรือนหุ้น >= 5%
3. เพดานอายุสิ้นสุดสัญญา: อายุผู้กู้รวมกับระยะเวลาผ่อนชำระต้องไม่เกิน 65 ปี
4. ประวัติค้างชำระ: หากเคยมีประวัติค้างชำระ ระบบจะไม่ปัดตกทันที แต่จะติดป้ายแจ้งเตือน (Flag) ให้เจ้าหน้าที่ตรวจสอบเพิ่มเติม

### 2. โมเดล AI และเกณฑ์ต้นทุนทางธุรกิจ (`src/model_trainer.py`, `src/business_evaluator.py`)
- ใช้ Random Forest Classifier ร่วมกับเทคนิค SMOTE ในชุดข้อมูลฝึกสอน (Train Set) เพื่อจัดการปัญหาสัดส่วนหนี้เสียที่ไม่สมดุล
- ปรับจุดตัดสินใจ (Threshold) จากค่าเริ่มต้น 0.5 โดยคำนวณจากสมการกำไรสุทธิ `(จำนวนลูกค้าปกติที่อนุมัติ * 12,000) - (จำนวนหนี้เสียที่อนุมัติพลาด * 50,000)`

## แนวทางการเชื่อมต่อกับระบบจริงของสหกรณ์ (สำหรับทีม IT)

1. การเชื่อมต่อฐานข้อมูล Sybase:
   - โมเดลชุดปัจจุบันเทรนจากข้อมูลสังเคราะห์ (`data_generator.py`) เพื่อทดสอบโครงสร้างระบบ
   - ก่อนใช้งานจริง ให้นำข้อมูลประวัติสินเชื่อย้อนหลังของสหกรณ์ (ผ่าน Read-only View) มาแทนที่ใน `main.py` แล้วสั่งรัน `python main.py` ใหม่เพื่ออัปเดตไฟล์ `best_credit_model.pkl`
   - ตั้งเวลา (Cron Job / Task Scheduler) ให้รัน `main.py` ซ้ำทุก 6-12 เดือน เพื่ออัปเดตโมเดลตามพฤติกรรมลูกหนี้ที่เปลี่ยนแปลง

2. การเชื่อมต่อกับ Platform หลัก (JavaScript):
   - หากต้องการเรียกใช้จากระบบหน้าบ้านของสหกรณ์โดยตรง สามารถนำฟังก์ชัน `apply_hard_filters` จาก `src/pre_screening.py` และไฟล์ `models/best_credit_model.pkl` ไปครอบด้วย REST API (เช่น FastAPI หรือ Flask) เพื่อรับข้อมูลผู้กู้และส่งผลประเมินกลับในรูปแบบ JSON
   - กรณีต้องการปรับแก้ตัวเลขกำไร/ขาดทุนเฉลี่ยของสหกรณ์ สามารถแก้ไขค่าตัวแปร `PROFIT_PER_GOOD` และ `LOSS_PER_BAD` ได้โดยตรงในไฟล์ `src/business_evaluator.py`
